# MxMesh AI — Assets

This directory contains the visual assets used throughout the **MxMesh AI** project.

---

## Purpose

The `assets/` directory provides a centralized location for images and other visual resources used by the MxMesh AI repository and its documentation.

---

## Directory Structure

```text
assets/
├── logos/
├── banners/
├── screenshots/
├── diagrams/
└── examples/
```

### `logos/`

Official MxMesh AI logos and branding assets.

### `banners/`

Repository and documentation banners.

### `screenshots/`

Screenshots showing development progress, experiments, interfaces, and results.

### `diagrams/`

Architecture diagrams, AI pipelines, workflows, and technical illustrations.

### `examples/`

Example input images and visual results used to demonstrate MxMesh AI.

---

## File Naming

Use descriptive file names with hyphens instead of spaces.

Examples:

```text
MxMesh-AI-Logo.png
MxMesh-AI-Banner.png
Image-to-3D-Pipeline.png
Colab-T4-GPU-Test.png
3D-Viewer-Example.png
```

---

## Using Assets in Documentation

Assets can be referenced from Markdown files using relative paths.

Example from the main repository README:

```markdown
![MxMesh AI Logo](assets/logos/MxMesh-AI-Logo.png)
```

Example from a file inside another directory:

```markdown
![MxMesh AI Logo](../assets/logos/MxMesh-AI-Logo.png)
```

---

## Asset Categories

| Directory | Content |
|---|---|
| `logos/` | MxMesh AI branding and logos |
| `banners/` | GitHub and documentation banners |
| `screenshots/` | Development evidence and application screenshots |
| `diagrams/` | Architecture and workflow diagrams |
